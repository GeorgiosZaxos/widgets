# Bundled asset provenance (FR-ASSET-010)

All bundled glyph catalogs (bars, borders, spinners, large and vertical fonts, symbols,
colours) are derived from the project owner's own legacy modules (`border_types.py`,
`barstyles.py`, `spinners.py`, `large_text_characters.py`, `vertical_large_text_characters.py`,
`unicode_*.py`, `color_constants.py`) and are released under the project licence.
Symbol names come from the Unicode Character Database via `unicodedata` (Unicode licence).
The 26 punctuation glyphs added to the large font were drawn for this project.
**Owner confirmation of authorship is still required before release.**
